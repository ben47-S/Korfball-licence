# Police Roboto pour la génération PDF

## Téléchargement

Téléchargez **Roboto-Regular.ttf** et placez-le dans ce dossier.

### Option 1 : Lien direct
https://github.com/google/fonts/raw/main/apache/roboto/Roboto-Regular.ttf

### Option 2 : Google Fonts
1. Allez sur https://fonts.google.com/specimen/Roboto
2. Cliquez sur "Download family"
3. Extrayez `Roboto-Regular.ttf`
4. Placez-le ici : `public/fonts/Roboto-Regular.ttf`

## Structure attendue

```
public/
└── fonts/
    └── Roboto-Regular.ttf
```
